ГЛУБИНЫ МОРОКА — проект для сборки APK

Способ 1 (без Android Studio): залей эту папку в новый репозиторий GitHub.
Во вкладке Actions запустится "Build APK"; готовый app-debug.apk скачай из Artifacts.

Способ 2: открой папку в Android Studio и выбери Build > Build APK(s).

Игра лежит в app/src/main/assets/index.html (прогресс сохраняется в памяти приложения).
Шрифты подгружаются из интернета, без сети будет запасной шрифт — игра работает и так.

Игра в приложении всегда в горизонтальной ориентации.
